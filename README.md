# Public Space (Fullstack)

This bundle contains both frontend (React) and backend (Express + Mongoose) for the Public Space app.

Quick steps:
1. Set MONGO_URI in backend/.env or environment variables.
2. From backend: `npm install` then `node index.js`
3. From frontend: `npm install` then `npm start`
4. Or use root `npm run dev` to install & start both (requires npm and internet).

Note: Do not commit credentials to public repos.
